Что важно знать

Открытые данные. Все инструменты работают с публичным API Caps Game. Никаких приватных данных, кошельков и балансов игроков не собирается и не показывается.
Сообщество. Проект сделан энтузиастами сообщества и не связан с разработчиками Caps Game.
Кэширование. Все запросы к API кэшируются на 15 минут в браузере — это снижает нагрузку на игру и ускоряет повторные открытия.
Первоисточники. Игра — @CapsGameBot, Wiki — GitHub Wiki, новости — EN и RU.
Исходный код. Проект открытый — весь код на GitHub. Присылайте баги и идеи через Issues.
